# Synthflow Asset Picker — Vibe Bucket

Shared vibe-curation gallery for Synthflow's Figma asset estate. The team
sweeps the libraries (Social Media & Ads, Marketing), keeps outside pieces
in the shared **Custom** library (uploads), pools vibe-based good pieces
into the shared **Vibe Bucket** (one-click picks, attributed, with
consensus badges), and exports the pool as a self-contained moodboard.
The in-app "?" button explains usage.

- Live picks go through the Cloudflare Worker in config.json's bucket_url;
  everyone sees the pool within seconds. The Custom library (upload / drag &
  drop, remove your own) is served by the same Worker and appears only while
  it is reachable.
- If the Worker is unreachable, picks queue in-browser and **Submit picks**
  opens a pre-filled GitHub issue; a repo Action merges submissions into
  `bucket.json` for everyone.
- Generated by `build_share.py` in the design repo's curation pipeline;
  renders are recompressed copies (q75, max edge 1200px).
