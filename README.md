# Synthflow Asset Picker

Static, shareable gallery of Synthflow's Figma asset estate (multi-file,
with a file switcher). Browse the libraries, pick assets into the shared
bucket, deep-link into Figma.

- Live picks go through the Cloudflare Worker in config.json's bucket_url.
- If the Worker is unreachable, picks queue in-browser and **Submit picks**
  opens a pre-filled GitHub issue; a repo Action merges submissions into
  `bucket.json` for everyone.
- Generated by `build_share.py` in the design repo's curation pipeline;
  renders are recompressed copies (q75, max edge 1200px).
