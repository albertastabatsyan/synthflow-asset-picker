# Synthflow Asset Picker — Vibe Bucket

Shared vibe-curation gallery for Synthflow's Figma asset estate. The team
sweeps the libraries (Social Media & Ads, Marketing), pools vibe-based good
pieces into the shared **Vibe Bucket** (one-click picks, attributed, with
consensus badges), uploads outside pieces directly, and exports the pool as
a self-contained moodboard. The in-app "?" button explains usage.

- Live picks and uploads go through the Cloudflare Worker in config.json's
  bucket_url; everyone sees the pool within seconds.
- If the Worker is unreachable, picks queue in-browser and **Submit picks**
  opens a pre-filled GitHub issue; a repo Action merges submissions into
  `bucket.json` for everyone (uploads need the Worker).
- Generated by `build_share.py` in the design repo's curation pipeline;
  renders are recompressed copies (q75, max edge 1200px).
