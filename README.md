# Synthflow Asset Picker

Small-team asset funnel for Synthflow's Figma estate:

- **Library** exposes the raw Social & Ads and Marketing catalogs.
- **Review** holds promising candidates.
- **Ready** groups finished assets by concrete production Needs.
- Figma-backed cards link directly to their source nodes; uploads stay in the
  current browser.
- The Cloudflare Worker shares picks, Need assignment, titles, usage notes and
  Ready status. If it is unavailable, queued changes remain visible and can be
  submitted through the GitHub-issue fallback.

Generated by `build_share.py` in the design repo's curation pipeline. The
runtime is `index.html` + `support.js`; `asset-assessments.v2.json` is the
versioned derived assessment index. Renders are recompressed copies (q75, max
edge 1200px). Daily Worker snapshots remain the shared-state recovery log.
