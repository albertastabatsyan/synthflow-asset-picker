# Synthflow Asset Picker

Static, shareable gallery of the Social Media & Ads Figma estate.
Browse the library, pick assets into the shared bucket, deep-link into Figma.

- Picks queue in your browser; **Submit picks** opens a pre-filled GitHub issue.
- A GitHub Action merges submitted issues into `bucket.json` — everyone's picks
  show up for all viewers within a minute or two.
- Generated by `build_share.py` in the design repo's curation pipeline;
  renders are recompressed copies (q75, max edge 1200px).
